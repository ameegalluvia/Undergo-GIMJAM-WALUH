## 📖 About the Game

**UNDERGO** adalah sebuah game *2D Psychological Horror RPG* yang berpusat pada kisah **Johan**, seorang pria yang mendapati dirinya terjebak di dalam sebuah teater misterius yang dipenuhi oleh bayang-bayang kenangan masa lalunya. 

Bantu Johan mencari jalan keluar sembari menelusuri fragmen ingatannya sendiri. Ungkap rahasia kelam di balik panggung teater tersebut sebelum kewarasannya runtuh dan teater itu menahannya untuk selamanya.

---

## ✨ Main Feature

* 🧠 **Sistem *Sanity Bar* yang Menantang:** Jaga kewarasan Johan tetap stabil di tengah teror psikologis. Semakin rendah *sanity*, semakin mencekam realitas di sekitarmu.
* 🧩 **Puzzle Interaktif:** Pecahkan berbagai teka-teki berbasis lingkungan dan memori untuk membuka akses ke area baru dan mengungkap kebenaran.
* 🎨 **Visual *Pixel Art* Atmosferik:** Desain grafis *pixel art* yang detail dan artistik untuk membangun nuansa melankolis sekaligus mencekam.
* 🔊 **Atmosfer Horor Imersif:** Perpaduan tata suara dan narasi psikologis yang dirancang untuk membangun ketegangan secara perlahan.

## 🎮 Control

| Tombol | Aksi |
| :--- | :--- |
| **`W` `A` `S` `D`** | Bergerak (Atas, Kiri, Bawah, Kanan) |
| **`E`** | Berinteraksi dengan objek / NPC |
| **`Tab`** / **`I`** | Membuka atau menutup *Inventory* |
| **`F`** | Menggunakan *item* penambah *Sanity* |

## 🚀 How to Play

1. Kunjungi halaman [**Releases**](../../releases) pada repositori ini.
2. Unduh file rilis versi terbaru sesuai dengan sistem operasi perangkatmu.
3. Ekstrak file `.zip` yang telah diunduh ke dalam folder pilihanmu.
4. Jalankan file eksekusi game (`Undergo.exe`) dan gunakan *headphone* untuk pengalaman horor yang maksimal.
